# مطابقة قائمة رغبات بمكتبتك

اكتب قائمتك في جدول (Excel أو LibreOffice، ثم احفظه CSV). العمود الوحيد اللازم هو العنوان، والأعمدة الأخرى
تزيد الدقة. تُقبل أسماء الأعمدة بالعربية أو بالإنجليزية:

| العنوان | المؤلف | المحقق | الناشر | سنة النشر | عدد الأجزاء |
|---|---|---|---|---|---|
| الرسالة | محمد بن إدريس الشافعي | أحمد محمد شاكر | | | |
| البيان والتبيين | الجاحظ | | المطبعة العلمية | 1311 | |

ثم:

```bash
turath-match reconcile -l folder:~/Books -t csv:wishlist.csv -o out
```

## متى أذكر المحقق والناشر؟

إذا كنت تريد **الكتاب** بأي طبعة فاكتب العنوان والمؤلف فقط، وسيُعدّ الكتاب موجودًا متى وُجد العمل. وإذا كنت تريد
**طبعة بعينها** فاذكر محققها أو ناشرها أو سنتها: حينئذ لا يُعدّ موجودًا إلا ما اتفقت بياناته، ويوضع غيره في
«طبعة أخرى».

## أسماء الملفات

تقرأ الأداة اسم الملف على هذه الصورة، وكل جزء بعد العنوان اختياري:

```text
العنوان - المؤلف - ت المحقق - ط الناشر المدينة.pdf
```

والمجلد الذي فيه ملفات مرقمة (`01 - …`, `02 - …`) كتاب واحد متعدد الأجزاء. إن كانت أسماء ملفاتك على نظام آخر
فاستعمل نمطًا: `folder:~/Books::pattern:{author} - {title}`.

!!! tip "اسم ملف لا يدل على شيء"
    ملف اسمه `scan0042.pdf` يُعرف أحيانًا بحجمه: إذا كان حجمه مطابقًا لملف في أرشيف الإنترنت أو في روابط الشاملة،
    عرفت الأداة أصله ومؤلفه. أضف هذه المصادر بخيار `-c`.
