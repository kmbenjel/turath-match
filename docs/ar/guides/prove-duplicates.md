# إثبات التكرار

```bash
turath-match dups ~/Books
```

ملفان مكرران إذا تساوى حجمهما بالبايت **واتفقت خمس عينات** من كل منهما، كل عينة 64 كيلوبايت: البداية، والربع،
والنصف، وثلاثة الأرباع، والنهاية. فلا يُقرأ من الملف إلا 320 كيلوبايت، ولذلك يصلح هذا للمكتبات البعيدة على هاتف
أو خادم.

للإثبات القاطع أضف `--deep`، فتُحسب بصمة SHA-256 للملف كله في كل مجموعة.

```bash
turath-match dups ~/Books --deep --plan dedupe.tsv
```

لا تحذف الأداة شيئًا. خيار `--plan` يكتب خطة [planfs](/planfs/) تنقل كل نسخة زائدة إلى مجلد عزل، فتراجعها ثم
تنفذها. والنسخة التي تبقى هي أحسنها اسمًا: الاسم الذي يقرؤه نسق التسمية (`--profile`، والافتراضي `smart`) عنوانًا
ومؤلفًا يُقدَّم على اسم الماسح الضوئي أو الرقم المجرد (`scan_0007.pdf`)، ثم الاسم الخالي من علامة النسخة الثانية
(«- Copy»، «(1)»، «Copy of …»، «نسخة ثانية»)، ثم الاسم الأكثر أجزاءً، ثم المسار الأقصر:

```bash
planfs plan dedupe.tsv
planfs apply dedupe.tsv
```

!!! note "الملف الذي لا يُقرأ"
    إذا تعذرت قراءة ملف فإنه يأخذ بصمة خاصة به، ولا يُعدّ مكررًا أبدًا.
