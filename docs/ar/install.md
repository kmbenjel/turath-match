# التثبيت

تحتاج إلى بايثون 3.10 أو أحدث. لا تعتمد الأداة إلا على مكتبة واحدة من العائلة نفسها هي
[arabic-bib](/arabic-bib/) لتسوية النصوص العربية ومقارنة أسماء المؤلفين.

الطريقة الأسهل، بلا تثبيت دائم:

```bash
uvx turath-match demo
```

أو التثبيت في بيئة مستقلة:

```bash
pipx install turath-match
```

أو داخل مشروع بايثون:

```bash
pip install turath-match
```

تحقق من التثبيت:

```bash
turath-match --version
```

يذكر السطر الناتج أيضًا محرك النصوص المستعمل (`arabic-bib`).

!!! note "الشبكة"
    لا تتصل الأداة بالإنترنت إلا في أوامر `fetch` وخيار `--online`. وكل ما تنزله يُحفظ في
    `~/.cache/turath-match` فلا يُطلب مرتين، بمعدل طلب واحد في الثانية لكل موقع.

## الشاملة

إن كانت عندك نسخة الشاملة على جهازك فلا تحتاج إلى شيء آخر لقراءة فهرسها. أما بطاقات الكتب (المحقق والناشر
والطبعة) فتحتاج إلى Java 21 أو أحدث، وهي مرفقة مع الشاملة نفسها. انظر [قراءة نسختك من الشاملة](guides/read-shamela.md).
