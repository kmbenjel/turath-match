# البحث عن نسخ لما ينقصك

لكل كتاب مفقود (أو موجود بطبعة أخرى) تبحث الأداة في مصادر النسخ عن سجلات **للعمل نفسه**، ثم ترتبها: الطبعة
المطلوبة أولًا، ثم ما له ملفات معروفة الحجم، ثم ما ينشر مصدره بصمات الملفات.

## من ملفات محفوظة

```bash
turath-match fetch archive --search "طوق الحمامة|ابن حزم" --search "البيان والتبيين|الجاحظ" -o items.jsonl
turath-match fetch openiti -o openiti.tsv
turath-match reconcile -l folder:~/Books -t csv:wishlist.csv -c archive:items.jsonl -c openiti:openiti.tsv -o out
```

تجد النتائج في `out/copies.tsv` وفي التقرير: رابط كل نسخة، وعدد ملفاتها، وحجمها بالبايت، وهل هي الطبعة المطلوبة.

## بحث مباشر

```bash
turath-match reconcile -l folder:~/Books -t csv:wishlist.csv --online -o out
```

يبحث خيار `--online` في أرشيف الإنترنت عن كل كتاب مفقود، بطلب واحد في الثانية، ويحفظ كل جواب فلا يُطلب مرتين.

!!! warning "النسخة ليست بالعنوان وحده"
    كثير من مواد أرشيف الإنترنت دراسات عن الكتاب أو شروح له أو نسخ مكتوبة على الحاسوب. لا تعدّ الأداة النسخة
    نسخةً للكتاب إلا إذا اتفق العنوان والمؤلف بلا علاقة اشتقاق (شرح أو مختصر أو دراسة)، وتعرض الطبعة إن عُرفت.
    اقرأ صفحة العنوان قبل أن تضيف الكتاب إلى مكتبتك.
