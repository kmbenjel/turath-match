# قائمة المراجعة

كل احتمال لم يكفِ دليله يُكتب في `review.tsv` مع أسبابه، وآخر عمود فيه فارغ اسمه `decision`. افتح الملف في برنامج
الجداول، واكتب في هذا العمود واحدًا من:

| القيمة | المعنى |
|---|---|
| `same` | هما الكتاب نفسه |
| `different` | كتابان مختلفان |
| `related` | أحدهما شرح الآخر أو مختصره أو نحو ذلك |

ثم أعد التشغيل:

```bash
turath-match reconcile -l folder:~/Books -t csv:wishlist.csv -d out/review.tsv -o out
```

تُطبَّق أحكامك بطريقة `manual` وتبقى في كل تشغيل لاحق، فلا تراجع الشيء نفسه مرتين.

!!! tip "ابدأ بالأعلى درجة"
    رتّب الملف بعمود `score` تنازليًّا: ما فوق 0.6 غالبًا الكتاب نفسه بعنوان أطول أو أقصر، وما دون 0.5 غالبًا
    كتابان يشتركان في عنوان قصير.
