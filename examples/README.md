# Examples

`demo-report/` is the output of `turath-match demo -o demo-report`: the report (`report.html`, `report.md`), the
per-target answer (`status.tsv`), the review list (`review.tsv`), the copies found (`copies.tsv`), every decision
with its evidence (`matches.jsonl`) and the work crosswalk (`crosswalk.jsonl`). The inputs are in
[`src/turath_match/demo/`](../src/turath_match/demo/).
